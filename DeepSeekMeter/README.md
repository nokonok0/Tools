# DeepSeek Meter

パネルはCodex Meterと共通の明るい青灰色・青緑のテーマです。初期サイズは620×280（96 DPI相当）で、表の下の余白を削減し、履歴が多い場合は縦にスクロールできます。Windowsの高DPI画面では文字をネイティブ解像度で描画します。

DeepSeekのアカウント残高と、実測した消費ペースから推定する「枯渇までの時間」、DSH（DeepSeek Harness）のモデル・推論設定別トークン数を表示するWindows用トレイアプリです。

## 導入・起動

Windows、Python 3.11以降、uvが必要です。このフォルダで一度だけ次を実行します。

```powershell
uv sync --locked --python 3.11
```

`uv.lock`に基づいて専用環境`.venv`が作られます。その後は`DeepSeekMeter.pyw`をダブルクリックしてください。起動のたびにuvを実行したり、パッケージをインストールしたりすることはありません。

通常のウィンドウやタスクバー項目は表示せず、時計横のトレイに常駐します。

- アイコンに枯渇までの推定時間を表示します（`45m`、`20h`など）。計測中は`...`、未取得は`--`、残高なしは`0m`です。
- アイコンにマウスを重ねると、残高・枯渇までの推定時間・消費ペース・最終取得時刻を表示します。
- クリックすると、現在のモニターのタスクバー付近に小さなパネルを表示・非表示にします。
- パネルの外をクリックする、Escapeを押す、またはパネルを閉じると非表示になります。
- 右クリックメニューから表示・非表示、更新、終了を操作できます。
- 再度起動した場合は、重複起動せず既存のパネルを表示します。
- pystrayがない環境では通常のウィンドウとして動作し、閉じると終了します。
- Windows 11で新しいトレイアイコンが「非表示」になっている場合は、タスクバーの設定からDeepSeek Meterを表示してください。

## 通常／軽量の一括切替

パネル右上の「通常／軽量」ボタン、またはトレイの右クリックメニュー「軽量モード（Meter共通）」で、DeepSeek MeterとCodex Meterをまとめて切り替えます。もう一方へ約1秒で反映し、再起動後も維持します。

通常は10秒、軽量は30秒ごとにログを確認して再集計します。軽量時は表示・通知の反映も遅くなります。新規ログの探索間隔など、既存の読み取り条件は変えません。「更新」は待機を解除して実行します。残高取得は5分ごとのままで、履歴保存・ログの記録時刻による活動区間の判定・推定式・読み取り上限は変えません。パネルの寸法も維持します。

共通設定は`%LOCALAPPDATA%\MeterCommon\runtime.json`に保存します。追加の常駐プロセスや予定タスクは使いません。RunCatのFPSは連動させず、RunCat自身のメニューで指定します。

## パネルの表示項目

- 「残高」はDeepSeek Platformのウォレット残高（通常残高とボーナス残高の合計）です。
- 「枯渇まで」は、残高を実測の消費ペースで割った連続使用可能時間の目安です。`20h`、`45m`のように表示します。
- 「消費ペース」は、直近3時間の残高減少を、DSHの作業が動いていた時間で割ったUSD/時です。
- 「本日」「24時間」「累計」は、保存済みの残高観測から求めた消費額です。「累計」はPlatformが返す累計消費額を使います。
- 一覧はモデル・推論設定ごとの呼び出し回数とトークン数（入力・キャッシュ・出力・合計）です。行を選ぶと、キャッシュ書込・初回・最終使用時刻を含む内訳を確認できます。
- パネルは既定の640×400を維持します。

## 推定方法と制限

- 残高は約5分ごと、手動更新時、起動直後に取得します。残高の観測間隔が15分を超える区間、残高が増えた区間（チャージ）、DSHの作業が動いていない区間は消費ペースの学習から除外します。
- 学習には直近3時間のうち2区間以上・実測10分以上・$0.001以上の消費を必要とし、それまでは「計測中」です。
- 消費ペースは残高の減少とDSHのターン実行時間から求めます。別の端末・Web・APIでの利用や、請求反映の遅れは推定に影響します。残高の表示丸めや作業内容の変化でも変動するため、保証された残り時間ではありません。
- 残高の取得に5分以上成功しない場合は、直前の残高と推定値を「前回値」として残します。古い残高を現在値とみなしたり、チャージを仮定したりしません。
- モデル別のトークン数はDSHのセッションログに記録された呼び出し単位の値だけを加算します。累積値との二重計上は行いません。表示合計は読み取れた範囲の記録で、請求額ではありません。
- 1ファイル（zstdは8MiB、無圧縮は64MiB）を超えるログ、64ファイルを超える対象、64MiBを超える展開結果は読み取り範囲外とし、不完全な状態を表示します。

## 自動起動・通知

Windowsへのサインイン時に自動起動する場合は、導入後に次を実行します。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Install-Startup.ps1
```

ユーザーのスタートアップフォルダに、`.venv\Scripts\pythonw.exe`を直接起動する`DeepSeek Meter.lnk`を作成します。アプリのフォルダを移動した場合は再実行してください。

残高が1.00ドル（人民元なら7.00元）以下、0.50ドル（3.50元）以下になったときにトレイ通知を表示します。各水準につき一度だけ通知し、残高が水準より十分上がると再度通知できるようになります。通知の識別情報は`%LOCALAPPDATA%\DeepSeekMeter\notifications.json`に保存します。通知の表示可否はWindowsの通知設定にも依存します。初回起動時に既に低い残高でも通知せず、状態だけを記録します。

## データとプライバシー

- 残高の取得には、DSHが保存しているDeepSeekアカウントの認証情報（`%USERPROFILE%\.dsh\.credentials.yaml`の`deepseek-account-platform/default`）を読み取り専用で使います。トークンはメモリ上だけで使い、保存・表示・送信先の変更は行いません。認証が切れている場合はDSHでの再ログインを促します。
- 通信は`https://platform.deepseek.com`への残高取得だけです。モデルの推論、CLI、MCPサーバーは起動しません。
- 保存するのは、モデル名・推論設定・時刻・呼び出し回数・トークン数・残高・通貨・累計消費額だけです。会話本文、ツール出力、コード、パス、アカウントID、トークンは保存しません。
- DSHのセッションログ（`%USERPROFILE%\.dsh\sessions`配下の`session.v*.jsonl.zstd`または`.jsonl`）は読み取り専用で走査します。
- 保存先は`%LOCALAPPDATA%\DeepSeekMeter\observations.json`です。原子的な書き込みで、最大2分に一度と終了時に保存します。日数・件数による自動削除は行いません。
- 既存のDSHファイルは変更しません。
